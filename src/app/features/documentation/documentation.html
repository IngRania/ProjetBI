Limites de l'analyse

  • « Gagnant » signifie ici un classement dans le top 10, pas uniquement la première place.
  • Plusieurs divisions sont présentes dans les données (élite, équipes, catégories d'âge) : les rangs ne sont pas tous comparables entre eux.
  • Petits effectifs : pour un pays ou une salle avec peu d'athlètes, le rang moyen est peu fiable.
